# Security Policy

## Supported versions

Only the latest major version (2.x) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately via
[GitHub Security Advisories](https://github.com/sebdrapier/netip-ts/security/advisories/new).
You should get a response within 7 days. Parsing bugs that let malformed input be
accepted (e.g. bypassing an allow-list check) are in scope.
